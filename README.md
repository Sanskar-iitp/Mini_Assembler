# Custom Assembler and Emulator

## How to Run the Code

### 1. Compile the Source Files
Use a standard C++ compiler (such as `g++`) to compile the source code into executable programs.
```bash
g++ asm.cpp -o asm
g++ emu.cpp -o emu
```

### 2. Run the Assembler
The assembler takes a `.asm` source file (Some sample test files are given) as input and generates a binary object file (`.o`) and a listing file (`.lst`). 
```bash
./asm program.asm
```
* **Success Output:** `Assembly successful (<X> records) -> program.o program.lst`
* **Error Handling:** If there are syntax or semantic errors (e.g., duplicate labels, undefined variables), the assembler will print the errors and abort the object file generation.

### 3. Run the Emulator
The emulator executes the machine code contained in the `.o` binary file. 
```bash
./emu [options] program.o
```
**Options:**
* `-t`: **Trace mode.** Prints the Program Counter (PC), Stack Pointer (SP), A/B registers, and the executed instruction for every step of the program.
* `-d`: **Dump mode.** Prints a hex dump of the first 64 words of memory after the program finishes execution.

*Example running with trace and memory dump:*
```bash
./emu -t -d program.o
```

## Project Overview

This project consists of a two-pass Assembler (`asm.cpp`) and a virtual machine Emulator (`emu.cpp`) built for a custom instruction set architecture. It is designed to handle systems-level execution, memory management, and basic arithmetic/logic operations. 

### Assembler (`asm.cpp`)
The assembler processes human-readable mnemonic instructions into 32-bit machine code. 
* **Pass 1:** Builds the symbol table by identifying all labels and `SET` directives, and checks for basic syntax errors.
* **Pass 2:** Generates the machine code, computes PC-relative offsets for branching instructions, and performs semantic checks (like infinite loop warnings).
* **Features:**
  * Supports labels (e.g., `loop:`).
  * Supports `SET` to define constant values.
  * Supports `data` to allocate raw memory words.
  * Detects unused labels and provides warnings.

### Emulator (`emu.cpp`)
The virtual machine executes the 32-bit binaries generated by the assembler.
* **Architecture:** Features a 64K word (32-bit integer) memory space (`MEM_WORDS = 1 << 16`).
* **Registers:** Operates using four primary registers: `A` (Accumulator), `B`, `PC` (Program Counter), and `SP` (Stack Pointer).
* **Safety:** Implements strict memory bounds checking to prevent out-of-bounds access faults. It also includes a hard limit of 10,000,000 execution steps to gracefully exit infinite loops.

## Instruction Set Architecture (ISA)

The architecture supports the following mnemonics:

**Memory & Value Operations**
* `ldc value` : Load constant into A (B = A; A = value)
* `ldl offset` : Load local from stack (B = A; A = mem[SP + offset])
* `stl offset` : Store local to stack (mem[SP + offset] = A; A = B)
* `ldnl offset`: Load non-local (A = mem[A + offset])
* `stnl offset`: Store non-local (mem[A + offset] = B)

**Arithmetic & Logic Operations**
* `add` : Add (A = A + B)
* `sub` : Subtract (A = B - A)
* `shl` : Shift Left (A = B << A)
* `shr` : Shift Right (A = B >> A)

**Stack & Pointer Manipulation**
* `adj value` : Adjust Stack Pointer (SP = SP + value)
* `a2sp` : Move A to SP (SP = A; A = B)
* `sp2a` : Move SP to A (B = A; A = SP)

**Control Flow (Branching)**
* `br offset` : Unconditional branch (PC = PC + offset)
* `brz offset` : Branch if zero (if A == 0, PC = PC + offset)
* `brlz offset`: Branch if less than zero (if A < 0, PC = PC + offset)
* `call offset`: Function call (B = A; A = PC; PC = PC + offset)
* `return` : Return from function (PC = A; A = B)
* `HALT` : Stop execution
